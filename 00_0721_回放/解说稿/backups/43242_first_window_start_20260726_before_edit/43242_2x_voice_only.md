红队我想见贵妃，对阵蓝队一心想赢！双方满载鲜荔，从岭南果园启程，过朱雀门、进兴庆宫！

双方先走官道，直奔南岭驿。下个岔口分路！红队去江南码头，走官道。蓝队去梅关驿，走官道。红队准备接水路、压鲜度损耗。蓝队留在官道，更像要抢任务分和速度。

蓝队先派小分队探梅关驿，探路标记把任务处理从三轮缩到两轮；第二支小分队马上转去荆襄清障。蓝队主车率先进入梅关，限时过关任务拿下三十分，荆襄障碍也同步清除。随后双方分路：蓝队沿官道去荆襄，红队转向江南接水路。酷暑命中两队，鲜度损耗提高五成。红队到达江南码头后派队探查洞庭，又领取短程马；探路标记落地，洞庭障碍也被清掉。

红队启用短程马加速，先进入洞庭；探路把转运从六轮缩到三轮，红队顺利离站。蓝队随后到达荆襄，探路把任务从四轮缩到两轮，抵驿催运再拿三十分！

蓝队鲜度先跌破九十，一篓好果转坏；红队随后也过线，同样损失一篓。两队的保鲜压力一起上来了。

蓝队小分队先清掉武关障碍。红队、蓝队随后抵达洛阳驿，同时争夺快马！这匹快马到底谁能拿到呢？第一轮三拍都献贡，打平，各耗三篓好果，休整三轮。休整结束，第二轮再次争夺，三拍还是献贡，再度打平！连续两次平局触发冷却。冷却一结束，第三轮重开，仍是三拍献贡、平局休整；第四轮紧接着再开，结果还是平局！

冷却结束，第五轮快马争夺重开，三拍献贡，还是平局；双方各耗三篓好果，休整三轮。第六轮马上又来了！三拍依然镜像，结果再平！两队再次休整，快马也重新进入冷却。

第七轮重开，三拍献贡打平；第八轮接上，还是平局，快马再次冷却。酷暑命中两队，鲜度损耗提高五成。第九轮变牌：首拍献贡，蓝队鲜度跌破八十又坏一篓；后两拍兵争，仍然打平，双方再休整。

第十轮重开！前两拍双方同时兵争，第三拍蓝队前面已经投入两点护卫，不再加码，选择弃权；红队献贡，一比零拿下快马。红队完成领取，立刻使用快马加速，鲜度随后跌破八十，又坏一篓。蓝队则派小分队探查武关，挂上探路标记。红队借快马先到武关，再派小分队探查潼关。

红队已经先到武关，蓝队现在紧跟进站。蓝队探路生效，栈道复核任务从四轮缩到两轮；任务完成，任务分累计九十，送达不再打折。红队的潼关探路标记先落地，蓝队随后同样派队探查潼关，也挂上标记。

红队先进入潼关，探路标记把交接从四轮缩到两轮，红队完成交接后离站。宫宴冲刺开启，蓝队随后到达潼关；蓝队的探路标记同样生效，也用两轮完成交接。两队一前一后驶向朱雀门，红队保持领先。

哎呀，蓝队鲜度跌破七十，又坏一篓。红队先到朱雀门，蓝队随后追上，率先完成宫门核验，进宫啦！

蓝队送达成功！七十二篓好果，鲜度六十九点一三，总分六百二十七；任务分到九十，送达基础分二百四十拿满。红队还在朱雀门等待，鲜度跌破七十又坏一篓，果量分和鲜度分继续下滑。直到最后几秒，红队终于启动宫门核验！

红队宫门核验完成，进宫资格到手！紧接着开启疾行令，冲进兴庆宫，送达成功！六十八篓好果，鲜度六十六点三六，总分三百六十一。

六百二十七比三百六十一，一心想赢获胜！
